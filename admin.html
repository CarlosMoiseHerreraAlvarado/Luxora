Base de Datos en Firebase Firestore

Tu tienda ya funciona al 100% guardando cambios en este navegador. Cuando quieras sincronizar todo en la nube con Firebase Firestore para que todos tus clientes vean los cambios en tiempo real desde cualquier celular o PC:

  1. Entra a console.firebase.google.com y crea un proyecto gratuito.
  2. Activa Firestore Database (en modo producción o prueba con lectura pública).
  3. En Configuración del proyecto → Tus apps → Web (</>), copia tus datos de firebaseConfig y pégalos abajo (o en js/config.js).
Reglas recomendadas para Firestore (pestaña Rules en Firebase): 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
